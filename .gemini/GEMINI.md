# Generator for OCR model training datasets

## General instructions

- Use `uv` as project and package management tool. Run python with `uv run python ...`

## Python codestyle instructions

- Never leave inline comments
- Always write types. Use python >= 3.11 notation
- Never use relative imports

## Docstring instructions

- Always write brief docstrings.
- Do not write parameter descriptions for functions with less that 3 parameters

## Testing instructions

- Use `pytest` as testing tool. Run with `uv run pytest ...`
- Folder `tests` is used for test scripts. Structure under `tests` folder repeats structure under root folder of source code.
